# Prompt Engineering Practical

A hands-on repository containing Python programs
and practical exercises related to Prompt Engineering.

## Objectives
- Understand AI tools and prompting techniques.
- Practice Python programming.
- Learn GitHub repository management.
- Maintain project documentation.

## Tools Used
- GitHub
- Python
- Visual Studio Code
- AI assistants

## Project Structure
- code/student.py – Student details using Python classes.
- code/calculator.py – Basic mathematical operations.
- audit.md – Project audit and work log.
- requirements.txt – Dependencies.

## How to Run

python code/student.py

python code/calculator.py
